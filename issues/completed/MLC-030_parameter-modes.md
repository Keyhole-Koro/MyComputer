# MLC-030: 引数を「読む・書く・受け取る」の3つにする

| Status | Branch | Agent | Updated |
| --- | --- | --- | --- |
| Done | main | - | 2026-11-07 |

## Summary

`borrow T` と `borrow mut T` をやめ、引数の渡し方を `T x`（読む）、`borrow T x`（書き換える）、
`move T x`（受け取る）にした。キーワード `mut` はなくなった。

## Background

`borrow mut` が 242 か所、`borrow` が 68 か所あった。局所変数の `borrow mut` は 79 か所のうち
書き込みが見つかったのが 32 か所で、`mut` は書き換えの目印として働いていなかった。

読むか書くかの区別はメモリ安全に要る。`v.at(0)` の結果を持ったまま `v.push(x)` すると
バッファが動く。区別は残し、読むのを既定にして綴りだけを消した。

## Design

規範は `docs/design/mylang-values.md` の規則 P1、P2、B1、B4、B6、B8。

- 構造体と配列は以前から隠しポインタで渡っているので、呼び出し規約は変わらない。
- 本文が書き換える無印の引数は入口でコピーする（`copy_written_params`）。以前は呼び出し元の
  値まで変わっていて、規則 V3 に反していた。
- `drop` を持つ値は無印なら読むだけ。書き換えと move は E0601。
- 読むだけの窓を返す関数はなくした。`at` / `get` は `Option<borrow T>` を返す1つになり、
  `at_mut` / `get_mut` は消えた。
- ポインタでも借用でも配列でもない値への `*` を E0305 にした。
- `bytes.move` は `move` が予約語になったので `bytes.overlapping_copy` に改名した。

## Limits

- 無印の引数に大域変数を渡し、呼び出し先がその大域変数を書き換えると、見える値も変わる。
  以前の `borrow T` と同じで、規則 B7 の範囲。
- 呼び出しが作った所有値は、読むだけの引数へ直接渡せない（E0601）。一時値を drop する処理を
  足せばなくせる。
- `.unsafe.mln` の `&self.data[0]` は、呼び出しの引数か `borrow` の局所変数でなければ書き込みと
  数えない。`as_str()` のように呼び出し元の値を指す窓を作るため。
