# MLC-031: 全体の整理と未使用 export の検出

| Status | Branch | Agent | Updated |
| --- | --- | --- | --- |
| Done | main | - | 2026-11-07 |

## Summary

`borrow mut` の廃止に続けて、型と「なし」の表現を全体で整理した。未使用の `export` は
`make unused-exports` で検出でき、QA でも止まる。

## 変更

- **型。** `NodeId`、`UserAddress`、`Atomic<T>`。「0 はなし」を `Option<NodeId>` に。
- **フック。** 関数値の大域変数は 14 か所とも既定の関数で始まる。`= 0` はない。
- **文字列。** API の `char *` を `str` に。OS_CALL の経路は長さ付きで渡す。
- **表。** `consoles`、`instances` を `.model.mln` に。`gateway_slots` は pid で引くので残した。
  カーネルのスレッドとプロセスの表は pid がスロットに結びつき、割り込みの中で走査するので残した。
- **`Copy`。** `impl Copy` をなくし、move するのは `drop` を持つ値と生ポインタを持つ値だけ。
- **ローダー。** フラットバイナリの経路を削除した。MBIN でないファイルは `InvalidHeader`。
  以前はテキストファイルを読み書き実行可能でマップして動かしていた。
- **コンパイラ。** `semantic_walk.c` を分割し、`ref` と `mut` の名前を消した。

## 見つかったバグ

- `f()?` と `case f() of` が、選ばれなかった `case` の腕、三項、`&&` の右でも実行された。
  ループの条件では最初の 1 回だけ実行された。
- `Some` のタグが 0 で、新しい `Option` が `Some(0)` に見えた（規則 V1 に反する）。
- 構造体の引数を書き換えると呼び出し元まで変わった（規則 V3 に反する）。
- `*` と `->` が、番地でない値にも通った。
- 配列の代入 `T b[N] = a` が、1 語に収まる配列で番地を入れていた。
- アセンブラが、文のないファイルで落ちた。
- ジェネリックの本体が呼ぶ、定義元の import 先の関数と型が、呼び出し側で見つからなかった。
- `char *a[N]` の配列が要素 1 バイト分しか確保されず、後ろの大域変数を壊していた。
- `user_range_has_flags` がアドレス空間の最後のページで偽を返し、スタック上の引数を渡す
  `THREAD_SPAWN` が必ず `BadAddress` になっていた。
- 終わったスレッドの `join` が、スロットを空けてから終了コードを読み、0 を返していた。

## 残り

- `qa/unused-exports-allow.txt` に残るのは、MMU が立てるビットの定数 2 件だけ。
