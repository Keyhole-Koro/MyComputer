# [Feature] MyLangへの enum (列挙型) 機能の追加

## 概要 (Overview)
現在の MyLang 言語仕様には `enum` (列挙型) や `#define` などのマクロ機能が存在しないため、OSカーネル開発においてマジックナンバーを避けるために定数をグローバル変数 (`i32 TASK_RUNNABLE = 0;` など) として宣言せざるを得ません。
しかしグローバル変数を使うと、割り込みハンドラなどの超高速ループ内で「毎度メモリアクセスが発生する」というパフォーマンス上の懸念（微小とはいえOSの設計思想として好ましくない）が生じます。
可読性の向上と、実行効率（コンパイル時の即値展開によるメモリアクセスの回避）を両立させるために、言語機能としての `enum` をコンパイラに実装します。

## 要求仕様 (Requirements)
* MyLangコンパイラ (`MyComputer-1/system/MyLang`) の構文解析器を拡張し、`enum` キーワードを解釈できるようにする。
* コンパイル時に `enum` の各メンバーを評価し、アセンブリ（`.masm`）生成時には変数の参照ではなく **即値 (Immediate value)** に展開する。
* 構文のイメージ案:
  ```mln
  enum TaskState {
      RUNNABLE = 0,
      SLEEPING = 1,
      EMPTY = 2
  }
  ```

## 期待される効果 (Benefits)
1. **OSスケジューラの最適化**: 割り込みループ内での無駄なメモリアクセス（変数ロード）がなくなり、レジスタへの即値ロード (`movi`) のみに最適化されるため、カーネルのパフォーマンスが向上する。
2. **メモリの節約**: 定数が変数として宣言されなくなるため、実行時の `.data` や `.bss` セクションのメモリを無駄に消費しない。
3. **開発体験の向上**: コードの可読性と保守性が大幅に向上する。
