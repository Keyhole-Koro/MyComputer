# エミュレータへのディスプレイ（minifb）追加

## 背景
DOM-like OS のフェーズ2を進めるにあたり、カーネルから UI を画面に描画する必要があります。
しかし、現在 `MyEmulator` は純粋なコンソールアプリケーションであり、描画対象となるディスプレイデバイスが存在しません。

## 目標
`MyEmulator` に VRAM 領域とウィンドウ表示機能を追加し、カーネルからピクセルを描画できるようにする。

## タスク
1. **依存関係の追加**
   - `runtime/MyEmulator/Cargo.toml` に `minifb` クレートを追加する。
2. **VRAM マッピングの定義**
   - `runtime/MyEmulator/src/constants.rs` に VRAM のベースアドレス（例: `0x3000_0000`）とサイズを定義する。
   - 解像度は暫定的に `320x240` (32bit ARGB) とする。
3. **ウィンドウと描画ループの実装**
   - `MyEmulator` 起動時に `minifb::Window` を作成する。
   - カーネルの実行ループ（あるいは一定のインターバル）で、VRAM の内容を `minifb` のバッファに転送し、ウィンドウを更新する。
4. **ヘッドレス対応**
   - 既存のテストスクリプトが CI 等でコケないよう、`--headless` オプションや環境変数をサポートするか、必要時のみウィンドウを出すように制御する。
