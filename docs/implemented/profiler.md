# プロファイラ

MyEmulator が命令数を数え、MyProfiler（`tools/MyProfiler`）がそれを読む。「どの関数・どの
ソース行・どの種類のコード・どのプロセスとスレッドに命令が集中しているか」を出す。コンパイラの
e2e の命令数を基準として記録し、変更の前後を比べることもできる。

使い方は `tools/MyProfiler/README.md`、ファイル形式は `tools/MyProfiler/docs/formats.md` にある。

## 確定した設計判断

- **計測単位は命令数（cycles ではなく retired instructions）**。タイマーを使わず HALT まで動く
  プログラムは、毎回同じ命令数になる。起動中のシステムはタイマーが実時間なので一致しない。
  比べるなら e2e の表を使う。
- **計測する側とは分ける**。対象のコードは書き換えず、エミュレータが外から数える。計測で
  プログラムの動きが変わらない。
- **`--line-info` は機械語を変えない**。`.func`、`.loc`、`.cost` はコードを出さないので、
  イメージはフラグの有無でバイト単位で同じになる。テストで確かめている。
- **デバッグ情報はオブジェクトの末尾に任意で付ける**。ヘッダも既存の領域も変えないので、
  末尾のないオブジェクトはこれまでどおりリンクできる。
- **JSON は手書き（serde 等を足さない）**。エミュレータの依存を増やさない。
- **オフはゼロコスト**。`--profile` がなければ `profiler` は `None` で、分岐が1回増えるだけ。

## 誰が何を持つか

| 情報 | 持ち主 |
|---|---|
| `.func`、`.loc`、`.cost`（`mlc --line-info`） | MyLangCompiler |
| オブジェクトのデバッグ情報 | MyAssembler |
| `.map`、`.lines` | MyLinker |
| プロファイルの JSON、`profile.reset`、`profile.write` | MyEmulator |
| レポート、ソース表示、比較、基準の記録 | MyProfiler |

## 関数と行の解決

`.map` には、リンクに残ったオブジェクトの公開シンボルをすべて載せる。再配置の表は参照された
シンボルしか持たないので、以前は参照のない関数に名前がなく、その命令が直前のシンボルに
計上されていた。ブートの計測では呼ばれた 355 関数のうち 151 関数に名前がなかった。

非公開の関数は `.lines` の `func` 行が名前を持つ。アセンブラのタグ `name-[module:n]` では
ブロックラベルと区別できないので、コンパイラが関数の開始を伝える。

## プロセスとスレッド

- **プロセス**。ユーザープロセスはどれも `0x40000000` から始まるので、PC だけでは関数を決められない。
  集計はアドレス空間ごとに分け、各空間にテキスト先頭のページを添える。MyProfiler はこれを
  ビルド済みのイメージと照合して、どのプログラムかを決める。終了したプロセスのページ
  ディレクトリは再利用されるので、`PDBR` の書き込みごとにテキストを見直し、変わっていれば
  別の空間にする。
- **スレッド**。カーネルの `g_current_thread_slot` への書き込みでコールスタックを切り替える。
  カーネルの変更はいらない。アドレスは MyProfiler が `.map` から引いて
  `--profile-thread-var` で渡す。
- **割り込み**。割り込みは呼び出しと同じ扱いにし、`iret` で戻る。スレッドが切り替わると
  途中のフレームが残るので、戻り先は上位 64 フレームまで探す。
- **戻りの判定**。戻り先アドレスと SP の両方を見る。再帰の内側の呼び出しが、自分の呼び出しの
  次の命令へ分岐しても、SP が低いので戻りと間違えない。

## 既知の留保

- `.cost` はコンパイラが印を付けた範囲だけを数える。ローカル変数をスタックから読み戻す命令は、
  普通のコードとして数える。
- ジェネリクスの名前は型引数を落として `Text<>.len` と表示する。
- `.func` より後ろに置かれた、関数でないコードは、直前の関数に数える。
- `--profile` は 1 命令ごとにハッシュ表を更新する。ブートは約 1.5 倍で済むが、e2e の表は
  `genericI32ToString` の 1 本（24 億命令）に数分かかる。
