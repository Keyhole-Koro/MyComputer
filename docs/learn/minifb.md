# minifb クレート

## 概要
`minifb` は Rust 製の軽量でクロスプラットフォーム対応のフレームバッファ（ウィンドウ表示）ライブラリです。
MyComputer のエミュレータ (`MyEmulator`) において、カーネルが操作する VRAM（ビデオメモリ）をホスト側の画面に表示するために利用します。

## なぜ minifb か？
- **軽量・シンプル**: SDL2 や OpenGL 等の複雑な初期化を必要とせず、ピクセルの配列（`u32` のバッファ）をウィンドウに転送するだけのシンプルな設計。
- **依存が少ない**: GUI ツールキットを使わずに素早くウィンドウを作成できるため、エミュレータのディスプレイ出力用途に最適。

## 想定する利用方法
1. エミュレータのメモリマップ上に VRAM 領域（例: `0x3000_0000` 〜）を定義する。
2. エミュレータのメインループ内で `minifb::Window` を作成する。
3. 一定周期（例: 毎フレーム、または VRAM への書き込みが発生したタイミング）で、VRAM の `u32` ピクセルデータを `window.update_with_buffer()` に渡して画面を更新する。

## 注意点
- ヘッドレスモード（CI テストなど）で起動する場合は、ウィンドウを作成しないようにフラグで制御する必要があります。
